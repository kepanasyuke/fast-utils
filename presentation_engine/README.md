# fast-utils

Веб-приложение для автоматического редизайна презентаций PowerPoint.

Программа принимает файл `.pptx`, анализирует текст слайдов и создаёт новую презентацию с единым визуальным стилем. Для разных типов содержимого используются отдельные макеты: титульный слайд, экран кода, интерактивное задание, таймер, определение, таймлайн, Git workflow, цитата и сравнительный блок.

## Возможности

- загрузка исходной презентации через веб-интерфейс;
- автоматическая классификация содержимого слайдов;
- распознавание таблиц с оформлением строк и заголовков;
- сохранение изображений из исходной презентации и сборка сюжетных коллажей;
- выбор цветовой палитры бренда;
- QR-код для ссылки на задание или внешний материал;
- генерация нового файла `.pptx` с русскими системными шрифтами;
- запуск в GitHub Codespaces одной командой.

Движок использует разные композиции для титульных слайдов, таблиц, одиночных изображений, коллажей, списков тезисов, IDE-кода, интерактивных заданий, таймеров, определений, таймлайнов, Git workflow, крупных утверждений и обзорных материалов. Макет выбирается по содержимому, а для обычных текстовых слайдов дополнительно меняется по ротации, чтобы презентация не выглядела набором копий одного экрана.

## Запуск

Выполните команды из этой папки:

```bash
make run
```

После запуска откройте порт `8000` в панели **Ports** GitHub Codespaces. Для ручной установки зависимостей используйте `make install`.

## Структура

- `app.py` — FastAPI-сервер и движок генерации презентаций;
- `requirements.txt` — Python-зависимости;
- `Makefile` — команды установки, запуска и очистки;
- `generated_presentations/` — созданные презентации.
