# fast-utils

Веб-приложение для автоматического редизайна презентаций PowerPoint.

Программа принимает файл `.pptx`, анализирует текст слайдов и создаёт новую презентацию с единым визуальным стилем. Для разных типов содержимого используются отдельные макеты: титульный слайд, экран кода, интерактивное задание, таймер, определение, таймлайн, Git workflow, цитата и сравнительный блок.

## Возможности

- загрузка исходной презентации через веб-интерфейс;
- автоматическая классификация содержимого слайдов;
- распознавание таблиц с оформлением строк и заголовков;
- сохранение изображений из исходной презентации и сборка сюжетных коллажей;
- распознавание блок-схем, пошаговых алгоритмов и слайдов с таймерами;
- отдельная кодовая панель с номерами строк и безопасным ограничением высоты;
- автоматическое разбиение длинного материала на несколько связанных слайдов;
- обработка сгруппированных объектов PowerPoint и векторных WMF/EMF-иллюстраций;
- выбор цветовой палитры бренда;
- QR-код для ссылки на задание или внешний материал;
- генерация нового файла `.pptx` с русскими системными шрифтами;
- запуск в GitHub Codespaces одной командой.

Движок использует разные композиции для титульных слайдов, таблиц, одиночных изображений, коллажей, блок-схем, списков тезисов, IDE-кода, интерактивных заданий, таймеров, определений, таймлайнов, Git workflow, крупных утверждений и обзорных материалов. Макет выбирается по содержимому, а длинные блоки автоматически распределяются по нескольким слайдам, чтобы презентация не превращалась в набор переполненных экранов.

В папке также находятся учебные исходники серий `7-1`–`7-5`. Их можно загружать по одному через веб-интерфейс; движок сохраняет изображения, таблицы, текст и элементы схем из исходного `.pptx`.

## Запуск

Выполните команды из этой папки:

```bash
make run
```

После запуска откройте порт `8000` в панели **Ports** GitHub Codespaces. Для ручной установки зависимостей используйте `make install`.

## Структура

- `app.py` — FastAPI-сервер и движок генерации презентаций;
- `layout_engine.py` — модели контента, измерение текста, геометрия и проверки layout;
- `requirements.txt` — Python-зависимости;
- `Makefile` — команды установки, запуска и очистки;
- `generated_presentations/` — созданные презентации.

## Архитектура редизайна

Обработка разделена на этапы: извлечение объектов из PPTX, семантическая классификация, выбор шаблона, построение геометрии и проверка результата. Движок отдельно обрабатывает таблицы, изображения, сгруппированные объекты, блок-схемы, формулы, код, задания, решения и длинные учебные тексты.

Текст перед размещением измеряется по зоне и размеру шрифта. Если материал не помещается, он разбивается на связанные страницы. Для изображений используется пропорциональное вписывание с полями, поэтому схемы и подписи не обрезаются. После генерации проверяются границы всех объектов слайда.
